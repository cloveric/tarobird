## 追加复现与修订

- **V01**：复现 Kimi 聊天/cron 并发启动读错工作区指令。锁覆盖指令准备到 ACP 会话完成启动，不只保护写文件。另修复启动后、首轮注册前进程退出导致等待挂住；保留实际错误并拒绝发送 prompt。
- **V02**：抢占操作只取消授权前记录的待执行任务，授权等待期间新加入的 `/q` 消息保留；仍先授权再取消。
- **V03**：合法短回复与旧回复前缀相同不再触发清空会话与自动重跑。文字相似仅记诊断，错轮次由协议身份检查处理。
- **V06**：Bot 规格/密钥先完整写入私有临时文件再排他发布，拒绝覆盖既有文件；仅清理数据库已完成附件的精确残留 chunk，保留上传中附件。
- **V10（部分）**：CLI 配对导出文件的 `stat` 失败仍关闭句柄；无法核实文件身份时不删除该路径。

## 构建、测试与文档

- **B01/B02**：Dockerfile 补齐实际构建输入、插件源码和当前 CLI 入口，使用 Node 24；客户端最低 Node 与依赖一致，根主机仍支持 Node >=20.17。Windows 通知审计 crate 独立工作区命令可执行。Docker 引擎未安装，真实镜像构建尚未验收。
- **B03**：同步 bus 错误、timeline 通道、AGY 档位、发送作用域和 Hub schema；说明本机认证 HTTP 与原生证书固定的适用范围，历史性能记录标明基线，不代表当前所有设备均已验收。
- **T01–T03**：改用可移植临时路径、实际持有的子进程、分平台权限断言；补跨用户附件、跨 chat/topic 停止与审批、真实排队取消、符号链接外逃等负例。源代码复现钩子未命中即失败，最终答复检查终态，吊销检查拒绝空集假通过。
- Gateway 测试守卫补 Node 24 CommonJS/ESM 两条 SDK 导入路径，避免测试意外调用旧通道。这只是测试隔离工具，不是产品安全沙箱。

## 保留边界与后续验收

- V04：身份未知的进程锁保持保守处理；不盲删锁或重放未知投递。尚未证明需要更换当前进程身份协议。

## CLI 与大组网一致性

CLI、桌面与手机继续共用主机核心；此次 CLI 直接改进的是更新故障报告、状态诊断及配对导出清理，其他共享修复自动适用于无界面运行。危险附件打开提示和 AbortSignal 兼容为客户端行为，无新增 CLI 命令需求。

覆盖 Codex、Claude、Antigravity、Kimi、DeepSeek 的已有适配器回归，不把协议模拟测试等同于五个真实 CLI 的本机实跑。主机身份、网络成员关系、Bot 归属、手机独立配对、默认模型权限和原生 20 分钟兜底期限均未改变。

本轮为源码修复，不是安装包发布。未更新当前安装的桌面/手机 App，未重启生产主机或 Bot。后续发版仍需按 release checklist 同源发布 App 与独立 CLI，并完成对应平台验收。
