## 保留的取舍与未完成平台验收

- Agent Bus 与 Bot 直接消息授权保持独立；开放直接消息权限不修改 Bus 流程或授权。
- Diff v1 只展示 Bot 配置工作区，保留跨平台安全文件名限制、严格快照刷新规则；不声称抵御任意同一操作系统用户的并发恶意文件系统写入。
- 已确认存活的锁持有者可执行长任务；未知持有者有等待上限，调用方可取消。不因等待五分钟直接抢锁。
- ASR 作业因主机崩溃而无法确认终态时保守显示中断；损坏安装记录需显式恢复。模型缺失检查提前到重型依赖导入前，但没有改变服务监督器持续重启策略。依赖与模型的全量 hash 锁定列为后续工作。
- Crew 的专用阶段预算不随普通 Bus 长 HTTP 超时一起扩大。缓存预览切换语言、设备 emoji 命名校验一致性、非 owner 授权页轮询等体验改进不扩大本轮修复范围。
- Windows/MSIX 重定向、原生 Windows 冷启动，Linux/systemd 与 GPU，Android/iOS 真机均需对应平台验收。Mac 上的策略测试、WebKit 和交叉打包仅证明各自边界。
- 客户端依赖审计的中等级链路位于 Word 转换依赖的命令行参数解析路径；当前预览不调用该路径，不采用破坏功能的大幅依赖降级。主机生产依赖没有审计告警。
- GitHub 当前源提交的 Source checks 与首次 Secret scanning 均在执行步骤为 0 时失败，平台明确返回账户付款或额度限制；新增标签触发的扫描仍排队。本次以本地结果和发布产物复核为准，没有将云端记录写成通过。

systemd 字段按 [官方执行环境说明](https://www.freedesktop.org/software/systemd/man/latest/systemd.exec.html#WorkingDirectory=) 的路径语义处理，未以静态配置检查替代 Linux 原生启动验收。
