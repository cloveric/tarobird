# 项目状态

更新：2026-10-19。本页导航当前产品范围；具体测试数字和安装状态以对应发行记录为准，不能将历史通过项当成本次审计的验收。

## 已提供的功能

- 桌面与手机共享聊天、Bot/群组/话题、多主题、文件与媒体、问答审批、个人删除与多选、草稿和搜索。
- 桌面专属 ADHD 多对话面板，可选择、排序多个对话并独立调整显示密度；Agent Bus 将本机协作流程、成员对话、阶段任务及执行状态可视化。
- App 与无界面 CLI 共用 Hub、身份、权限、持久化队列、历史同步、文件上传和配对/组网。已授权 Bot 可经 CLI 跨主机发送任务与取回回复；Agent Bus 仍仅在同一主机运行。
- Codex、Claude、Kimi、DeepSeek、Antigravity 使用各自协议提供能力；不假定每种引擎都支持同一套操作。
- 局域网/Tailscale/可选 VPS 中转、多主机路由、后台推送、定时任务、用量和运行过程查看。

## 发行与验证边界

[1.0.94 / CLI 0.1.442 发行记录](client/release-1.0.94-2026-10-19.md)列出了 Mac、Windows、Android 和独立 CLI 安装包及校验结果，Hub schema 为 19。Mac 与 Android 已有 App 内更新路径；安装包和更新服务各自的签名、权限及系统确认仍需遵守原生平台约束。

- Mac 包使用 ad-hoc seal，未宣称 Apple 公证。打包/启动检查不等于所有原生交互都验收过。
- Windows、Android 的每次交叉编译和包内容校验，不等于对应版本在实体设备上完整测试。
- iOS 工程可编译，模拟器已有基础验证；仍无已签名的 IPA / TestFlight 发行。
- 原生内存、所有引擎和网络组合的长期稳定性仍需持续实测，不宣称低于 200 MB 或“没有 bug”。
- GitHub Actions 受账户费用/额度限制未能启动；本地测试记录不能冒充云端 CI 通过。

源码后续审计修订不会自动替换已安装 App。修订内容与本地/真机验证分别记录，发布时遵循[发布清单](release-checklist.md)。

## 架构、安全与文档

入口见[代码地图](entrypoint-map.md)、[使用指南](client/user-guide.md)和[验收门槛](client/acceptance-gates.md)。CLI 命令为 `tarobot`；旧应用 ID、状态路径和部分协议字段保留兼容，详见[命名边界](neutral-naming.md)。

Telegram/飞书是可选适配器，不是 App 的消息链路，App 发版不重启这些服务。原生三端有主机身份与 TLS 固定；浏览器预览的首次信任边界单独见[安全说明](security-boundaries.md)。

原始聊天、凭据、机器路径、日志和截图不进入仓库。`docs/client/evidence/` 的新原始产物默认被忽略，已跟踪的脱敏发行凭据有意保留；首页产品图使用合成数据。历史实现记录中的本地证据不是公开下载。
