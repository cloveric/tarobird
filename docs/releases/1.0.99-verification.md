## Boundaries and local installation

Windows is cross-built and has no Authenticode signature or native machine acceptance. No physical Android/iPhone is connected; no iOS Simulator runtime is installed. iOS 15.0–15.3 was not tested; the existing client uses Array.prototype.at, which needs 15.4+. The new observer usage does not establish older-runtime compatibility.

GitHub Actions did not start because of account payment/spending limits; local tests are not called successful GitHub CI.

Local Mac: guarded replacement subsequently installed App 1.0.99 and Host
0.1.447, retaining identity/history and confirming schema 21 and recorded-diff,
delta-snapshot and side-conversation capabilities. The native window was observed
connected and displaying successful message/reply traffic. The user's subsequent
DD1 query exposed the signing regression above; the [1.0.100 follow-up](1.0.100-verification.md)
tracks its fix and separate installation. No forced shutdown or old-database
rollback was used.
