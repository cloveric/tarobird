## Product and runtime changes

The release includes the larger welcome artwork and platform-specific branding,
more compact iOS navigation, readable narrow iOS conversation titles, ADHD
header shortcut removal, retired avatar choices with saved-avatar compatibility,
and illustrated Bot/network documentation. These presentation changes do not
add or remove headless CLI commands.

Electron is 45.2.3 and bundled Node.js is 24.22.2. Direct runtime dependencies
were checked against current upstream versions; build/test dependencies were
updated. TypeScript 7 compiles the project while the stable TypeScript 6 API is
installed under an explicit alias for tooling that uses the compiler API.
Excalidraw 0.18.1, Vditor 4.0.1 and the Baoyu 2.9.0 editor/skill pin were checked
against official upstreams. Ninety upstream editor/reference/helper files were
byte-compared; two local vendor documentation hashes were checked separately.

## Privacy and migration

Fresh staged, outgoing-commit and full-history checks passed before the source
push. Exact signed archives/installers and unpacked contents were scanned for
owner paths, identifiers and secrets, including UTF-16 and archive metadata.
Mac tar ownership is neutral and native paths are remapped. Independent secret
scan findings were limited to exact reviewed public upstream fixtures and a
JavaScript comparison. The base64-embedded worker fixture was decoded and fully
matched against three copies in the official upstream archive; no directory-wide
exception was added. Publication text was separately reviewed and scanned.
These checks do not certify removal of historical content from the old archive
or guarantee detection of every possible private value.

The updater's actual OAuth device flow verified access to the new private
repository. The one-time installer rehearsal copied the final signed DMG over
an isolated copy of the previous App, preserved identifiers/signing keys and
synthetic external state, and verified the new repository configuration. Real
CLI upgrade tests separately exercised retained Host data. This rehearsal did
not install over the production App or exercise its GUI/Keychain access.

## Evidence boundaries and retained retries

GitHub Actions jobs did not start because of account billing/spending limits;
they are not reported as passing. Local checks actually ran. Production-only
npm audits report zero vulnerabilities; development-tool findings are separate.

Initial preparation checks exposed CRLF normalization in Git archive output,
a missing generated Host resource, and stale icon expectations in a private
verification script. The relevant checks were corrected and rerun. Two routing
harness matchers misclassified explanatory text/layout; actual skill choices
and read tools were manually inspected. The first isolated DMG mount location
was rejected by macOS; a supported unindexed mount location passed. Original
failure records were retained, not replaced with fabricated successful runs.

Windows remains a manual-install prerelease without an automatic-update
manifest or Authenticode certificate. Native Windows install/custom-path
upgrade/uninstall acceptance remains pending. No physical-phone, real remote
screen-control or installed production-App acceptance is claimed. This release
did not replace or restart the owner's running App/Host.

The automatic global artifact cleanup hit its bounded discovery limit and
performed no removals. A reviewed cleanup restricted to the current and previous
release workspaces then moved five eligible old temporary Apps to Trash and
preserved 28 recent/current Apps. The latest 1.1.1 backup passed signature
verification and did not appear in the Spotlight query. The installed App was
not modified.
