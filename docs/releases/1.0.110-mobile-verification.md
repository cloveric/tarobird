## Scope and compatibility

This release packages the [compact phone composer](../client/phone-composer-tools-2026-10-24.md): the task-history entry and Claude send choice share one row. At the 390-wide browser fixture, the ordinary composer occupies 104 instead of 146 CSS pixels. Full background progress, management, stop-impact notices and pending-message controls remain available.

Only Android and iOS are published. Mac/Windows remain **1.0.109**, and Host/CLI remain **0.1.456**. No Host/protocol/schema or command changes; wire protocol 1 and schema compatibility 1–21 remain unchanged. No CLI archive is rebuilt or republished. The phones keep working with existing paired hosts; no Mac replacement, Host restart or local CLI update is performed.

The shared client package supplies mobile frontend and iOS marketing versions. Desktop native metadata and Host package versions deliberately remain unchanged. A read-back confirmed the installed Mac still reports App 1.0.109 and bundled Host 0.1.456.
