## Changes

This release includes the original selected-list copy, sparse streaming, desktop file/audio and LAN pairing fixes, plus all eight user follow-ups and the [joint-review corrections](../client/followup-joint-review-2026-10-27.md). Voice attachments, mobile Bot grants, side-chat copy, mixed-script Chinese bold and process-search colors are corrected.

Host behavior is shared with the CLI; renderer-only changes require no new CLI commands. Source commits and focused tests are recorded in the linked implementation documents.
