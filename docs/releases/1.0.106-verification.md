## Joint review and corrections

Codex and actual Claude Opus 5.5 (`claude-opus-5-5[1m]`, xhigh) reviewed the
October 23 changes. The [audit disposition](../client/release-audit-1.0.106-2026-10-23.md)
distinguishes reproduced defects from hypotheses and retained behavior.

The final integration clarifies that first-time authorization needs pairing;
already paired devices changing trusted routes retain authorization. Host URLs
and ports are visible and copyable, read-only refresh has completion/failure
feedback, and route entry uses “添加此主机的其他地址”. It also fixes video cover
frame/data ordering, video aspect ratio, and side recording retention when
Escape is pressed or attachment slots are full. DOMPurify is updated to 3.4.17.
Android cutout restoration now retains the framework field type without lint
suppression; the initial candidate was superseded before any publication.

Earlier accumulated changes cover group discussion/draft guards, Claude tasks
and supplementary input, explicit pending queues, per-conversation temporary
side panels, attachment interactions, image menus, ADHD navigation and platform
visual boundaries. These shared Host capabilities retain App/CLI API parity.
The additional media and address presentation fixes do not introduce a separate
headless implementation. `network local --tailscale --json` reads the same
Host status.

Current Claude Code foreground interrupt may also cancel its background
subagents. Ordinary supplementary input does not trigger that stop. Independent
preservation of every native background job is not promised.

## Local activation and remaining acceptance

The existing guarded desktop-update handoff waited for accepted work, made an
offline database/configuration snapshot, replaced the App atomically and
restarted the actual Host. Host PID changed from 67082 to 37762; seven Host
children were present, draining was false and the configured VPS relay was
online. The installed binary, Node and Host package metadata match the verified
bundle. Identity bytes match the snapshot; every prior Bot, conversation,
message and device row ID remains. Schema 21, authenticated reconnect, new
Host capabilities and installed external-addon loading passed.

Finder's Applications folder opened the installed App in the foreground. Chat
history and the composer rendered, Settings displayed 1.0.106, and the connected
Host/network entries worked. The LAN and saved Tailscale addresses include their
ports; the panel states that already paired devices do not need pairing again.
A read-only Tailscale refresh visibly updated its completion time. At inspection,
LAN was listening; Tailscale was enabled with a saved address but not listening.
The original conversation was restored without changing preferences, preparing
routes or sending a test message. These observations cover the inspected screens,
not every navigation path or physical-phone behavior.

The single detached Opus watcher emitted a completion notification. A delayed
Android blocker notification referred to superseded source `af5466e`; its lint
error was already corrected in final `4a88efc`. No lint suppression was added,
and only the final source's packages were published.
