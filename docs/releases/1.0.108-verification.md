## Retained limits

Old Host preflight has a non-atomic final-read-to-drain admission window and cannot observe unpublished work or disconnected/removed workers. Cross-Bot completion describes known reply records, not success of every subtask. Native Claude alias ownership is coordinated within one Bot process.

Physical iPhone/Android installation, push delivery, real tailnet/cellular routes and native Windows installation/launch are not independently re-accepted in this release. Windows has no Authenticode signature. macOS is Apple Silicon. Browser and Simulator checks are not physical-device acceptance.
