## Android runtime acceptance not performed

Before publication, the Android 1.3.0 App was **not installed and launched on a
physical Android phone or Android emulator for runtime acceptance**. No such
startup/flow acceptance receipt exists for this release. In particular, the
following changed-App flows were not verified on either surface:

- Connecting the Android App to a Host.
- Android push delivery in the App.
- Native keyboard/layout behavior.
- The Android in-app update flow.

Build, Lint, JVM/unit tests, browser viewport checks and package verification
must not be treated as evidence that these Android App flows passed. The
`verified` fields in packaging receipts refer to their recorded package scope,
not physical-device or emulator App acceptance.

Private evidence is retained under the release task's `release-1.3.0-20261111`
directory; raw logs and local paths are not published in this repository:

| `platforms/android-verified.json` | APK/package checks, Gradle results and unit/Lint counts |
| `platforms/logs/android-gradle.log` | Assembly, unit-test and Lint tasks |
| `logs/android-transport-upstream.log` | JVM transport audit explicitly excluding an Android device |
| `mobile-ready.json` | Package evidence; `physicalDeviceVerified: false` |
