# TaroBot iOS 1.0.111

Frozen source: [`b0b17841b4a353b532728236f01ff88225dcb555`](https://github.com/cloveric/tarobot/commit/b0b17841b4a353b532728236f01ff88225dcb555). iOS build **1**. Published to the existing internal TestFlight group on 2026-10-25.

## Scope

This iOS-only release includes [iPhone Duo adaptation](../client/iphone-duo-2026-10-25.md): window-based keyboard geometry, safe-area layout, folded/unfolded and rotated layouts, wide-iOS attachment entry points, and a scrollable share extension in short windows. Current conversations, drafts, attachments and send choices survive tested viewport transitions. It also updates the client Zod dependency to **4.6.7**.

Android stays **1.0.110**; Mac/Windows stay **1.0.109**; Host/CLI stay **0.1.456**. No Host restart, local Mac replacement, CLI archive, Android/Windows release, protocol change or schema migration. Protocol 1 and schema compatibility 1–21 are unchanged. The installed Mac version was read back as 1.0.109; the unrelated Android wrapper change was preserved byte-for-byte.

CLI parity: these are iOS presentation and client validation changes, so there is no new headless operation. Existing Host/CLI packages and commands are retained. Packaging/upgrade gates for a new Host are not applicable to this release.

## Client validation dependency

A bounded local probe reproduced excessive field-error accumulation for an oversized array in client Zod 4.6.5. The client update to 4.6.7 rejects that oversized array with one size error. Two focused regression tests also preserve valid text/indentation and ordinary field-error reporting. Clean client `npm audit` reported zero known vulnerabilities at release time.

Vite dedupes Zod to the client's installed dependency. **This is not a Host dependency upgrade**: the root lockfile remains at Zod 4.3.6, and existing Host packages were neither rebuilt nor replaced. Host-side dependency remediation remains a separate follow-up; the client scan is not evidence that the entire application dependency tree is clear. Reference: [the reviewed Zod advisory](https://github.com/advisories/GHSA-mrhx-c7xc-m3w5).
