## Joint review and regression evidence

Codex and actual Claude Opus 5.5 (`claude-opus-5-5[1m]`, xhigh) independently
reviewed the previous audit's updates. The [disposition record](../client/post-audit-review-2026-10-23.md)
describes reproduced defects and controls: route status and stale diagnostics,
historical synchronization, official restore lineage, side-session reservations
and attachments, daily maintenance, recovery diagnostics and widget execution.
The speculative native Mac animation workaround was withdrawn after the
original signed App rendered correctly when opened in the foreground via Finder.

The final frozen-source gate passed **454 test files, 6,206 tests, five skips**,
Host and frontend builds, a clean frontend dependency installation, desktop Host
preparation, and **77 native Rust tests**. Focused browser tests cover Chromium
and WebKit, including actual IndexedDB restore races. Opus separately reviewed
the final integration fixes and passed its 210-case focused regression set.

GitHub-hosted [source checks](https://github.com/cloveric/tarobot/actions/runs/39872067201)
and [secret scanning](https://github.com/cloveric/tarobot/actions/runs/39872067207)
did not start because of the account's failed-payment/spending-limit restriction.
Local required checks, including secret scanning, passed. Remote CI is not green.

The canonical CLI passed clean extraction/installation and verification outside
the source checkout, then an isolated existing-host upgrade from 0.1.451 to
0.1.452 retaining identity, controller, network and workspace. Mac and Windows
bundled Host bytes match the canonical package.

The extracted CLI also passed ten live checks using real Codex and Claude CLIs:
text and two-client synchronization, byte-verified file return, local ASR,
question submission/resume, and streaming stop/resume with retained context for
each provider. The boundary was paired App protocol → real Hub → separate
Gateway worker → real CLI. This does not prove physical-phone or tailnet paths.
The first ASR attempt on external-volume state failed in the installed ASR
service's ffprobe timeout; identical WAV bytes on internal temporary storage
returned the expected transcript, and the full ten-check run passed there.
That environment-specific failure remains recorded; no service permissions or
production ASR configuration were changed, and its precise OS cause is unproven.

## Installation and outstanding network acceptance

The Mac update used the existing guarded desktop-update handoff: accepted work
finished, an offline database/configuration snapshot was made, the App was
replaced atomically, and the actual Host restarted. Identity/history retention,
schema 21, authenticated reconnect and external-addon loading all passed. Host
PID changed from 25485 to 94515, its seven child processes were present, draining
was false, and the configured VPS relay reported online. A detached Opus helper
delivered one completion notification; no grants or schedules were changed and
no active work was forcibly interrupted.

The installed App was opened in the foreground using Finder's Applications
folder. Chat history, the live response and composer rendered visibly; Settings
opened, identified version 1.0.105, and the network panel showed the connected
local Host with distinct Add device/QR, connection status/routes, and device/
network entries. Closing Settings restored the original conversation. No
preference was changed or test message sent. These observations cover those
screens, not every navigation path or iPhone scrolling performance.

Tailscale still reports **NeedsLogin** on this Mac at publication. Issues
[#53](https://github.com/cloveric/tarobot/issues/53) and
[#59](https://github.com/cloveric/tarobot/issues/59) remain open for the physical
tailnet/cellular, P2P/DERP, multiple-host and sustained-reconnect matrix. Already
paired devices retain authorization and reconnect over trusted reachable routes;
tailnet membership itself does not grant TaroBot access. Native installation,
browser tests and protocol-only live checks do not satisfy that network matrix.
