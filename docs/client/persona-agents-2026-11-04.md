# Bot 人设作为 AGENTS.md 的一个小节

2026-11-04，按 Owner 确认的范围实现：每个 Bot 的人设是普通文件中的一段指令；
修改后需要当前对话使用新版时，让 Bot 从磁盘重新读取即可。没有新增人格系统、
文件监听、后台应用状态机或因人设更新而强制重启会话。

## 文件与编辑

唯一生效来源为 `<Bot 状态目录>/workspace/AGENTS.md`。这是该 Bot 的默认私有
工作区，即使某条对话切换到共享项目，编辑器仍只操作这个 Bot 自己的文件。
默认工作区或 AGENTS.md 是符号链接时拒绝修改，避免改到共享项目或其他 Bot。

App 和 `tarobot bots persona ID [--from PATCH.json]` 编辑以下标记之间的文本：

```markdown
## Bot persona

<!-- TaroBot persona: start -->
用中文回答，先说结论。
<!-- TaroBot persona: end -->
```

小节外的规则原样保留，包括 BOM 和换行格式。没有小节时在文件尾部追加。
人设限 16,000 字符，整个指令文件限 1 MiB；标记损坏或重复时拒绝自动修改。
revision 覆盖整个文件，因此其他设备或编辑器修改工作规则后，旧草稿也会报告冲突。
人设格式、大小或迁移问题只阻止不安全的编辑；Bot 启动记录诊断后继续，保留原文件，
不把可选人设变成整个 Bot 启动的前置条件。
如果旧人设超长或文件标记损坏，编辑器会报错，需要人工修复；保留的旧 `agent.md`
不会继续注入模型，因此这类异常文件不能保证人设继续生效。
并发 App/CLI 保存共用文件锁，原子写入；上一版完整文件保存在 `AGENTS.md.previous`。
手动编辑不参加 Host 文件锁，应在保存前刷新编辑内容，避免同时写同一个文件。

手动清空后，两个边界标记紧挨着的行也视为空小节（LF/CRLF 均支持）。
清空只移除小节内的内容，保留边界标记和其他规则。模型已有会话历史保留；
清空文件并不删除历史，需要模型重新读取并按最新要求继续。

## 旧数据与引擎入口

启动 Bot 或第一次访问新版人设 API 时，旧 `<状态目录>/agent.md` 的内容迁入
小节。若 AGENTS.md 已有小节（包括空小节），以现有小节为准。原 `agent.md`
保存为 `agent.md.migrated`，写入和备份成功后才移除旧入口。回滚到旧 Host 后
重新写入了不同内容时，再保存一份带内容 SHA-256 后缀的备份，保留第一次备份；
已有小节仍为准，旧 Host 自动创建的空文件也不会覆盖它。备份永远不作为读取回退，
所以之后清空或删除 AGENTS.md 不会仅因备份存在而复活旧人设。
升级期间不要让旧 Host 和新 Host 同时管理同一个 Bot；回退旧 Host 时需人工核对
迁移备份，不能把新文件语义当作旧版本已支持。

engine-factory 不再给各适配器传旧人设 `instructionsPath`。原生平台说明继续由
Host 维护，不写入 AGENTS.md。Bridge 的私有轮次说明仅给出该 Bot 文件的准确路径：
尚未读取时读取；用户要求重新读取时再次读磁盘。同一文件内容不再分别注入 Codex
additionalContext、Claude system prompt 或复制到 DeepSeek 私有 home。
Codex 恢复线程所选的旧工具 schema、Claude 原生 App 工具路径及普通回退路径均保留
该文件引用。Bridge 侧问发送会转发路径并保留原有只读约束；Codex 侧问会消费这段说明，
Claude 侧问不消费轮次说明且没有文件工具，只能使用父会话历史中已经读到的人设，
不能在侧问中重新读取文件。稳定工具配置和后台任务生命周期不因人设文本变化而改变。
独立原生 Goal 等其他执行入口未做真实模型矩阵验收。

DeepSeek 启动私有 home 时，现有无 instructionsPath 分支清除旧 AGENTS.md
链接/副本；模型读取 Bot 工作区的原文件，Windows 不再依赖启动时复制的人设。
Kimi 仅沿用共用 factory 的路径调整，其原生 `.kimi-code/agents/agent.md` 格式和
平台说明同步逻辑没有改动。本轮按 Owner 要求不测 Kimi。

现有 `persona.get/set` 和 HTTP schema 不变，App 与 CLI 共用权限、错误和保存规则。
界面“刷新编辑内容”只刷新编辑框；保存提示只确认文件落盘，不冒充模型已读取。
对话里可以说：“从磁盘重新读取你自己的 AGENTS.md，后续按最新内容执行。”
如果对话使用自定义项目工作区，Bot 自己的文件可能位于引擎当前工作目录之外；
本机 Claude 的 manual/acceptEdits 模式在该路径尚未获准时要求读取授权；
auto 模式及 Antigravity 本机隔离探针可读取。App 审批卡及会话授权复用未在这组
探针中实测，不能保证每个引擎或平台相同。读取仍遵守原有权限，保存人设不会
自动扩大工作目录或绕过审批。参见[后续联合审阅](post-1.0.129-audit-2026-11-04.md)。
