# 运行回复的排版保真审计（2026-10-14）

本次由 Codex 检查实现、操作浏览器和执行回归；Claude Opus 5.5（xhigh）独立只读审查了代码，并在第二轮结合修改前截图复核。两轮模型回执均为 `claude-opus-5-5[1m]`，没有让审查者修改工作区。最终截图和测试由 Codex 验证。

## 结论与修正

旧 Markdown 解析器没有被删除。代码高亮、引用、表格展开、公式、链接和清单仍存在，但新运行回复未完整继承旧卡片的排版规则，详情页还有覆盖代码块样式的问题。

| 发现 | 复现与影响 | 修正 |
| --- | --- | --- |
| 新回复丢失卡片排版层 | 对照同一段标题、列表和正文；新回复缺少 `.card-text`，行距、缩进和强调色不一致 | 正文和公开过程文本复用旧卡片的排版层 |
| 过程中的复制按钮遮住代码 | 手机打开“运行过程 → 公开思考摘要”，首行代码落在复制按钮区域 | 收窄详情的 `pre` 规则；代码块预留独立工具栏位置 |
| 标题、公式在抵达 App 前已被降级 | Gateway 实时/最终回复依旧经过飞书 Markdown 转换 | App 保留标题和 TeX，继续保留中文引号加粗修复、代码原文和交付标签清理；飞书原有转换不变 |
| 特殊主题未覆盖原生回复 | 在完整 `.message` 容器中比较 CLI、Pixel、Mono | 补齐各主题对原生回复的样式，白色系列继续为白底 |
| 原始参数和输出不易单独复制 | 详情中只能复制整步 | 共用代码阅读器，独立复制参数/输出，带成功播报和失败提示；内容仍按转义文本呈现 |
| 长输出滚动后遮住复制按钮 | 在超过 360px 的原始输出内向下滚动 | 滚动视口放在工具栏下方，按钮不会盖住内容 |
| 过程列表改变正文列表圆点 | 过程本身的有序列表影响内部 Markdown 的嵌套层级 | 明确定义 Markdown 内部的列表层级；保留主题覆盖 |
| 详情交互影响聊天跟随 | 在过程搜索框按 ↑，或在详情内滚动 | 聊天滚动处理只接收来自自身 DOM 区域的事件，忽略 Portal 弹层事件 |
| 手机滑动时仍被拉回最新消息 | 连续输出中用可信触摸事件上下滑动；修订前也失败 | 被动跟随不再发起持续的虚拟列表索引定位，避免残留的 `reconcileScroll` 在用户滑动后继续追踪底部 |

代码块保留原始缩进、换行和局部横向滚动，增加语言标签和“复制 / 已复制”反馈。表格继续使用既有展开阅读器；缩略引用保持无操作按钮。没有增加虚构的思考内容、进度或引擎事件。

- `gateway-cards`、`run-presentation`：28 项通过；实时和最终 App 回复的标题、数学公式、代码及中文引号加粗有独立断言。
- 启用旧适配器测试后，`lark-card-renderer`：91 项通过，飞书兼容行为保持。
- `run-formatting`、`message-reading`、`conversation-entry`、`run-details-refresh`：17 项通过。涵盖手机/桌面、全部 13 种配色的浅色与深色对照、单独复制/失败反馈、原始输出转义与滚动、可信触摸上下滑动、延迟排版阅读锚点、详情更新和会话切换。
- `markdown`、`palettes`、五种引擎的 `run-presentation`：18 项通过，覆盖 Codex、Claude、Antigravity、Kimi、DeepSeek 的桌面和手机展示。
- `search`：4 项通过。旧测试依赖“我的主机”的默认文案，已显式设置测试主机名并校验真实主机名称，保留范围、分页和消息定位断言。
- 客户端生产构建、主机独立构建通过；主机构建图包含 325 个模块，无旧传输或飞书 SDK。

浏览器测试使用本机 Chrome，隔离测试配置和临时 Hub；iOS 触摸配置是浏览器模拟，不代表 iPhone 真机验收。五种引擎使用真实 App/Hub/Gateway 链路与模拟公开事件，不等于本轮调用了五个真实模型。未重启用户正在运行的主机，也未更改其对话或配对状态。

## CLI 与发布影响

界面排版和复制交互属于客户端。主机的 `cleanCardText` 修正由桌面与无头 CLI 共用；无需增加 CLI 命令，不改协议、数据库、身份或大组网语义。后续发行应从同一源版本打包 App 内置主机和独立 CLI。

本次为源码修订，不代表 macOS / Windows / Android / iOS 安装包或独立 CLI 已发布、已安装。已被旧主机转换并存储的历史文本无法从样式中还原丢失的 Markdown；新主机生成的回复可完整保留，已有原文的历史回复会使用新排版。
