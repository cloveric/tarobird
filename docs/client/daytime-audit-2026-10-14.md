## 判定边界

- 普通 choice 卡可由持久化卡片恢复；原生问题的回调目前仍在进程内。
  初审提出“所有问题都应放行”的推断经源码核对没有采纳，不能靠强制退出消除等待。
- 键盘测试原先用一个选择器同时要求两个远隔的按钮可见，改为分别滚动验证可达性。
  历史消息测试同毫秒插入后按随机主键返回，现固定消息及 replay 时间顺序。
  两项属于夹具问题，没有为测试改产品布局或重写滚动算法。
- WebKit 的密集证书二维码夹具改为使用产品自己的多尺度图片解码入口，仍解码实际
  渲染出的图片。单例重复验证通过，未改为直接读取二维码字符串。
- 测试启动时移除外层 Bot 注入的实例路由环境变量，防止临时 HOME 被生产实例路径覆盖；
  单个测试仍可显式设置这些变量验证优先级。
- Windows 旧票据没有 MachineGuid，改名后不能安全推断归属，仍保守拒绝回收；
  不把本机互斥协议用于多个容器、克隆系统或网络文件系统共享同一 state 目录。
  新 Windows epoch 由旧 reader 拒绝而非忽略，不能同时运行旧新版本争用同一状态。
- 配对的收尾等待仍持有桌面启动锁，防止并发启动改写配置；其他命令可能先达到
  默认 300 秒的未知身份等待上限。操作文档明确重试顺序，不在等待中擅自释放锁。
