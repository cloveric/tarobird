# Claude Opus 5.5 model correction — 2026-10-11

The App catalog and Claude engine defaults shared a stale explicit model ID,
`claude-opus-5[1m]`. New Claude Bots now select `claude-opus-5-5[1m]` with
`xhigh`. The model is passed through to Claude Code unchanged; this is not a
label-only fix. The existing 1M context suffix is preserved.

Existing saved model selections, sessions, workspaces and memory are not
migrated. A Bot previously created with Opus 5 can be changed with
`/model claude-opus-5-5[1m]` in its chat. An already-running Hub retains its
loaded catalog until it restarts; replacing the App alone does not restart it.
The command works immediately without restarting the Hub.
