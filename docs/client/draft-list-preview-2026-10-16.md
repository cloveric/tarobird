# 会话列表草稿预览

输入区原先已经保存草稿，但桌面侧栏和手机消息列表只展示最后一条消息。
现在两处都优先显示“草稿：内容”，前缀使用当前主题的强调色，内容保持单行
省略。换行折叠为空格，摘要限制为 160 个字符；输入区的原文不被改写。

只有附件时显示附件数量，只有引用时显示“引用回复”。仅选择收件 Bot 或
隐藏链接预览不算有待发送内容。清空文字、移除附件/引用或成功发送后，列表
回到最后消息。未发送的草稿不增加未读数、不重排会话，也不发送给模型。

群组折叠显示时，优先展示群内主对话草稿，否则显示可见话题的草稿并注明
话题名；话题独立行展示自己的草稿。原有打开群组/话题的导航保持不变。
手机“待处理”筛选中的审批/问题提示仍然优先，保留准确的请求跳转。

`DraftPreview.tsx` 为每个 `ClientCache` 共享一个只读观察器。文字和富草稿
提交后触发刷新，窗口重新获得焦点时重读；异步旧结果不能覆盖新结果。主机
和配对隔离沿用现有本机缓存，不增加跨设备草稿同步或第二套持久化数据。

IndexedDB 升至 v9，为现有富草稿添加 `files.length` 和 `reply.id` 索引。
索引自动覆盖旧数据，列表只读取文本和索引键，不加载附件二进制或引用正文。
原附件字节、CAS 修订保护、配额、身份撤销及清空机制继续使用原来的实现。

此变更是本机客户端输入状态的呈现，不新增主机能力，headless CLI 无需新增
命令。Codex、Claude 等引擎共用同一列表逻辑。
