## Release-gate file-lock regression

The baseline CI run41321182147 passed7806 tests but failed the concurrent AccessStore subprocess test: `mkdir(lockPath, recursive:true)` returned ENOENT while an empty lock container could be removed by another releasing process. Container creation was outside the existing retry guard. The narrow repair retries ENOENT from both directory-creation steps through the existing bounded, abortable wait; permission and other filesystem errors remain fatal.
