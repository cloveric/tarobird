# Daily product and runtime audit — 2026-10-14

Scope: the 70 commits from `eb9c29e` to `e3efb32`, covering the October 13 workday
and its continuation after midnight (481 changed files). The review includes
the five engine adapters, native run presentation, Bot collaboration, private
networks, pairing, folders, attachments, notifications, composer behavior,
mobile layout and desktop packaging. This is a bounded code and regression
audit, not a claim that every device or external provider was exercised.

The primary review was supplemented by client, runtime and native packaging
reviews and an actual **Claude Opus 5.5, xhigh** read-only CLI audit. Opus used
`claude-opus-5-5[1m]`; it inspected source and did not run the acceptance tests.
Findings were reproduced and verified separately before inclusion below. A
second Opus review found no new release-blocking issue and called out the
first-publication outbox edge case; the final patch covers that case using the
run's start time, with an additional failing-before/passing-after regression.

## Confirmed issues and corrections

| Issue | Correction and evidence |
| --- | --- |
| Result delivery or stop confirmation could be published as a completed reply, causing an early completion notification. | Gateway derives status from the native phase. Hub push and desktop notification handling also reject active phases. Regression covers all active phases, old Hub fallback, final completion and interruption. |
| Restarted workers could leave old cards spinning, including legacy `complete` delivery cards and scheduled/goal runs without an input delivery. | A capability-gated, authenticated startup sweep closes orphan native runs after outbox replay. Ordinary pending deliveries retain their durable receipt recovery; reconnects do not repeat the sweep. Results are preserved and engine actions are not rerun. |
| Continuous events repeatedly cancelled slow process-detail requests, leaving the panel loading indefinitely over a slower route. | Keep an in-flight read and coalesce revisions; cancel on query/page/connection changes or close. Regression uses 1,200 ms reads and 400 ms events. |
| Hitting the bounded journal's byte limit could discard tool completion or failure. | Reserve space for terminal metadata and retain the receipt even when its raw output cannot fit. Boundary tests verify status, exit code, duration, truncation and the 8 MiB ceiling. |
| Changing a computer name or route during an incomplete network join could permanently invalidate its retry. | Commit the exact admitted descriptor, then publish subsequent changes after activation. Reproduced failed-exchange, rename and route-update sequence now succeeds. |
| Background network synchronization could consume a join/leave result before the initiating command, reporting a successful operation as stale or revoked. | Serialize local commands against background synchronization while preserving transactional authorization and one-time proofs. Race and revoked-while-waiting regressions pass. |
| The final coordinating computer had no usable UI action to dissolve its otherwise empty network. | Show a local-desktop-only dissolve action with explicit effects and recheck membership before submission. Phones and remote desktops explain where to complete it. |
| Collaboration's “Enable and connect” button was white text on a white background. | Scope primary-button colors inside the preparation panel. Real rendered contrast and normal, hover and pending states are checked on phone and desktop in Chromium and WebKit. |
| Simultaneous desktop handshakes could show a misleading Keychain permission prompt message for a brief busy response. | Give busy/retry its own message; preserve the existing automatic connection retry and do not replay state-changing actions. Three concurrent host handshakes recover in browser-native transport fixtures. |
| The grouped-conversation capacity error incorrectly said there were too many folders. | Explain that the capacity includes archived conversations and how to release it. Preserve archived assignments for restoration; do not silently discard user organization. |
| Generic desktop CI could package a shell with missing or mismatched host resources. | Prepare platform-specific complete hosts and reject mismatched receipt, Node, native addons or missing payload at build time. Only verified macOS arm64 and Windows x64 combinations are packaged. |

The attachment-forwarding browser regression also had a race: it read the store
immediately after the dialog closed, before the Hub acknowledgement. It now
waits for actual persistence. No delivery behavior was weakened to satisfy it.

## Acceptance boundary

Five-engine protocol fixtures cover Codex, Claude, Antigravity, Kimi Code and
DeepSeek. They are not live paid-model calls. Browser checks use isolated Hubs
and fixtures, and include actual screenshot inspection; the invisible
collaboration button was caught by that visual pass rather than test counts.

The final installer checks and test results are recorded in the
[1.0.67 release evidence](release-1.0.67-2026-10-14.md). Android physical-device
push delivery still needs the application's Firebase configuration; no such
configuration is present in this release. This audit does not establish real
FCM delivery, Windows native execution, physical cross-machine pairing or Mac
Keychain behavior after an installed upgrade.

Opus also noted non-blocking legacy-card incremental output formatting and
bounded journal serialization overhead. These are not presented as resolved:
the native App journal preserves output chunks, while legacy transport-specific
formatting and a performance redesign remain separate follow-up work.
