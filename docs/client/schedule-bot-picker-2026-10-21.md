# 定时任务执行 Bot 选择界面

手机上原生 select 会打开系统单选弹窗，字号、颜色和间距脱离 App 主题。本次将“执行 Bot”替换为同一个 `CreationDialog` 内的选择页，桌面、手机与浏览器共用。

- 头像、Bot 名称、在线/离线状态和主题色勾选；使用现有名称消歧标签。
- 搜索全部当前主机 Bot，先显示 50 个，可继续展开；已选项置顶。离线可选，但仍须 Bot 在线才能保存任务。
- 返回按钮、系统返回、Escape 和遮罩只退回任务页，不关闭整个流程；不自动唤起手机键盘。列表独立滚动，标题、搜索和返回始终可见。少量 Bot 时选择页按内容收缩，多项时限制最大高度，不留固定高度的大片空白。
- 任务表单以 `hidden` 保留，切回后草稿、上下文展开状态与滚动位置不丢。选择同一个 Bot 不清空结果对话，真正切换时才清空；旧 Bot 的在途列表响应不能覆盖新选择。
- 编辑和未确认保存期间禁止换 Bot，原因在手机上可见。保存回执绑定 Bot ID，建对话和重试请求使用同一目标。
- 被删除的选择显示不可用并禁用保存，不自动选择另一个 Bot。读屏描述包含当前名称与在线状态，减少动态效果设置生效。

任务调度、权限及接口保持原规则。CLI 不适用：这是界面呈现和同一操作中保存目标的固定，不增加主机能力或另一套调度实现。执行频率、星期、结果对话和上下文选择仍使用原生控件。

## Codex 自测结果

- 客户端翻译、TypeScript 与构建通过。
- Chromium：手机触控 390px、桌面 1360px 两项选择器流程通过，含 50/64 个 Bot、搜索末项、空结果、草稿/展开状态保留、动态删除、离线、返回焦点、窄高窗口及长列表返回可见性、减少动画、浅色/暗色/CLI 截图。
- 真实隔离 Hub 多设备定时任务回归通过：创建、丢失回执重试、编辑、暂停、删除、旧任务兼容；新增编辑与重试时禁止换 Bot 及可见原因断言。未操作生产定时任务。
- WebKit 的独立空白页启动已被本机环境阻塞；未声称 Android/iOS 真机、原生 WebView 或真实读屏验收通过。未发版或更新安装包。

## Opus 审阅发现及处理

Opus 5.5 / xhigh 完成方案审阅、代码与九张截图复审，并独立操作一项隔离界面测试。确认无导航、草稿、串 Bot 或权限方面的阻塞问题。

已采纳建议：保留隐藏表单、恢复触发焦点及滚动位置、保存回执绑定 Bot、动态删除提示、选中项置顶；复审发现的读屏描述缺失、手机禁用原因不可见已补齐，长列表标题滚出屏幕与触摸悬停残留也已修正。后两项通过新增实际界面断言验证。双方无未决分歧。

增量复审提出少量 Bot 不应仍占用长列表高度；已改为内容自适应高度并补两项手机/桌面验证。2 个 Bot 时窗口低于 400px，原有长列表及 430px 窗口高度下的返回可见性断言继续通过。Opus 已复核此改动，未发现阻塞问题。
