## Findings and repairs

- **#87: legacy streaming-card width regression.** The fitted-toolbar grid
  matched `.rich-card.reply-card`, including older run cards identified by
  `config.streaming_mode`. In a production-component browser fixture a short
  card measured about 204px and expanded to 656px after a longer patch.
  Exclude these cards from the fitted-column rule; both running and completed
  forms keep their existing stable reading width. Ordinary fitted receipts and
  image batches still use the PR's toolbar alignment. Native run presentation,
  forms, questions and tables retain their own existing layout.
- **#89: source-host rows were still misaligned.** The reserved unread slot only
  covered `time:only-child`; a host label plus unread count produced a third
  line and increased row height. Use two grid rows, with the host label and
  unread count sharing the second row. Constrain the host label to its grid
  cell so long names cannot extend left over the title in a narrow sidebar.
  Four metadata combinations measured the same 56px compact row height after
  repair. Phone home rows use their separate existing layout.
- **#91: image counts moved behind long prose.** Appending the count to the end
  of the preview could truncate it even when the image originally came first.
  Emit one count at the first untitled image's position. Whitespace-only titles
  also count as untitled. Preserve named images, source block order, original
  message blocks and the existing 120-character preview limit.
- **#88/#90/#92:** retain the image-grid fitted card, existing danger-color token
  for the delete action, shortened avatar description and one-line host summary.
  Actual localized connection/sync labels were checked; the initially suspected
  overflow used an artificial label longer than the production copy and was not
  treated as a confirmed product defect. No unrelated redesign was added.

  navigation excerpts. No Host command, API, authorization, queue, persistence
  schema, message state or engine execution behavior changes.
