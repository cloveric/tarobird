# 显示未连接 Bot

手机和桌面列表增加「显示未连接 Bot」复选框，默认不勾选。手机消息列表中位于「按主机分组」旁，Bot 页和搜索/单个 Bot 的对话列表也保留入口。桌面按 Bot、按对话、合并主机和按主机分组视图共用同一设置。

## 行为

- `showDisconnectedBots` 是设备本地的列表偏好，与已有列表排列设置一起保存；不跨设备同步。旧设置没有该字段时默认关闭。
- 主机连接状态为 `online` 且 Bot 的实时 `online` 标记有效，才视为已连接。离线主机缓存中的旧在线标记不计入。
- 关闭开关时隐藏未连接 Bot 及其单聊，包括置顶单聊；开启即可恢复。在线主机明确报告某个 Bot 离线时立即筛选。已连接主机突然断线时，先保留断线前可见的 Bot 与单聊，连续断线满 5 分钟才隐藏；期间仍显示真实离线状态。
- 群组、话题和已无 Bot 成员的历史对话仍保留。筛选只作用于列表，不删除或归档记录，不改变置顶、分组、未读、草稿和当前打开的对话。
- 来源以主机身份和 Bot ID 一起判断，不会因为另一台主机上有同 ID 的在线 Bot 而显示本机离线 Bot。
- 对话确实被隐藏且列表为空时提示开启该选项；尚无对话时显示普通空状态。手机列表仍有内容时不显示额外的“未连接的 Bot 已隐藏”说明，节省纵向空间，保留上方复选框。仍有在线 Bot 时保留新建入口，不因其他离线 Bot 而消失。手机首页显示当前主机的断连恢复提示，见 [首页连接恢复](inbox-recovery-2026-10-17.md)。
- 从主机管理明确进入已停用主机的「查看历史记录」时，显示那台主机的完整历史，仍为只读。该例外不修改全局开关、不显示其他主机的隐藏记录，也不恢复主机授权。
- 主机管理、连接设置和 Bot 管理操作不受列表筛选限制。
- 显示离线记录时，桌面在线圆点也检查主机连接状态，避免旧缓存仍显示绿色。

## 实现与 CLI

`conversation-inbox.ts:navigationItems` 提供只读的列表筛选。`ConversationList`、`CombinedSidebar` 和 `MobileHome` 共用该规则；`SidebarLayoutSwitch` 提供复选框，`ClientCache` 和 `HostRegistry` 读取旧偏好时应用默认值。

`HubConnection` 为每台主机维护独立的 `navigationGraceUntil` 和一次性到期通知。
第一次从已认证在线状态转为离线/连接中时开始计时；线路重试、重复前台
信号、切换主机/页面都不延长。重新认证在线后清零，下一次断线重新计时。
后台休眠期间的时间也计入，唤醒时即使定时器尚未执行也立即检查期限。
宽限只影响列表，不延迟传输断开、不伪造在线圆点，也不增加发送权限。

只保留原本在线的 Bot，不让已经隐藏的离线 Bot 因主机断线重新出现。
冷启动尚未连接成功的主机、主动停用和授权吊销不启用这段宽限；显式历史
入口及“显示未连接 Bot”开关仍可显示相应缓存。群组和当前打开的草稿不变。

这是 App 显示偏好，不改变 Hub 的目录、权限、协议或 CLI 返回结果，CLI 不需要新增命令。

## 初版验证边界

浏览器使用两台隔离 Hub，覆盖同 ID 的 Bot、实时上下线、主机断开后的缓存、置顶、分组、草稿、偏好保存/重载、旧偏好默认值、搜索，以及手机和桌面切换。原有列表、主机来源和手机 Bot 浏览流程也做定向回归。

- `npm run build --prefix client`：翻译、TypeScript 和前端构建通过。
- `npm run build`：355 模块的独立主机构建通过，不引入旧传输层依赖。
- Chromium：12 个不同用例通过（11 个现有回归用例，以及修正测试断言后单独通过的新增完整流程）。
- WebKit：3 个不同用例通过（2 个手机 Bot 浏览回归，以及单独通过的新增完整流程）。
- 人工查看 320/390 像素手机和桌面截图，无横向溢出；关闭时隐藏、开启时恢复的视觉效果已检查。
- 新测试最初错误地认为按离线 Bot 名称搜索应隐藏该 Bot 参与的群组；断言已按“群组保留”的产品规则修正。偏好重载验证等待 IndexedDB 写入完成。

## 第二轮独立审查

实际调用 Claude Opus 5.5，命令明确设置 `--effort xhigh`，完成只读审计及补丁复核。先用浏览器复现了两个问题：默认隐藏离线 Bot 后，明确打开已停用主机历史仍看不到其他历史单聊；零对话时仅因存在离线 Bot 就误报隐藏并丢失手机新建入口。两处修复均新增回归验证。

历史消息测试不运行 Gateway，因此必须明确开启「显示未连接 Bot」。现有离线夹具显式选择该选项并等待偏好持久化，真实 Gateway、默认值和上下线测试保持原条件；回复 Bot 测试选择器也限定到对应控件，避免误认列表中新加入的复选框。

浏览器验收不等同于 Android 或 macOS/Windows 原生 App。安装包及完整发布验收见 [1.0.84 发布记录](release-1.0.84-2026-10-17.md)。
