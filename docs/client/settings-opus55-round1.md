## 2. 分组和手机流程

方向我同意，但建议分 **4 组**，不单独做"关于"：
- **通用**：头像、语言、主题、字号；桌面版再放开机自启、快捷键、版本和更新。【码】开机自启现在混在通知组件里；更新组件在非桌面端什么都不显示，单独一组"关于"在网页和手机上会是空页。
- **通知**
- **连接**：不叫"连接与主机"，免得让人以为这里能管理主机。
- **设备与安全**：设备列表、应用锁、危险操作区。

手机用"分类列表 → 详情页"不算过度设计，前提是：
- 只用一个状态记录当前分类，不引入路由库。
- 列表每行带上当前值，比如"连接 · 主机直连 · 在线"、"通知 · 已关闭"。
- 【图03】顶部"主机直连 · 5ms"的状态标签，点击后直接打开连接页，成本很低。

这几样这轮不要做：单独的"测试连接"按钮、线路配置同步、自动判断部署角色。

## 3. 本轮落地方案

**布局**
- 桌面：约 760px 宽，左侧导航 180px，右侧内容单独滚动，标题栏固定。
- 手机（≤760px）：全屏页面，顶部固定并留出刘海安全区，左上「‹ 设置」，右上×。
- 支持 Esc 关闭；焦点限制在面板内，关闭后回到打开它的按钮。

**首次连接**
- 主按钮「扫码连接」，下面一条分隔线「或手动填写」。
- 输入框「主机地址」，提示：「运行 Bot 的主机地址，或中转 VPS 的地址。公网必须使用 HTTPS。」
- 链接「+ 添加备用中转」，默认不显示空白中转行。
- 折叠项「我不确定该填什么」，部署方式下拉和安全说明都收在里面。
- 扫码后显示「已从二维码读取：直连 1 条、中转 2 条，Hub 身份已锁定」，隐藏手动填写区，留一个「改为手动填写」。

**连接页**
- **查看状态**：「正在使用：{线路} · 在线」或「未连接，正在按顺序重试」。下面列出已保存的线路和各自可用状态（沿用现有的状态文案）。说明文字：「线路只保存在本设备，不会安装、迁移或检测服务器，也不会同步到其他已配对设备；新设备扫码会带入这里已保存的线路。」
- **编辑状态**：点「编辑线路」进入，每次进入都重新读取已保存配置。部署方式收进折叠项「部署方式（仅用于说明和命名）」。底部固定一栏：「有未保存的更改」＋［取消］［保存线路］。
- 有未保存改动时，关闭、Esc、切换分类、返回都先弹确认：「放弃未保存的线路更改？」［放弃更改］［继续编辑］。
- 保存成功沿用现在的文案，**不要写成"已连接成功"**。
- 页面上一直注明：「备用中转只保护线路；主机停机时中转无法替代，也不缓存离线文件。」

**设备与安全**
- 「添加新设备」展开成一个连续流程：
  1. 显示二维码，附说明「包含 Hub 身份和本设备已保存的线路，不含凭据；新设备仍需在此批准」。
  2. 输入 8 位配对码（数字键盘、支持系统自动填充验证码），旁边有「扫描配对码」，然后点「批准」。
  3. 成功后提示「已批准」，并清空输入框。
- 当前设备只标「本设备」，不显示吊销按钮。
- 吊销其他设备前确认：「吊销「{名称}」？该设备会立即断开，需要重新配对才能使用。」
- 危险操作区放在页面最底部，保留现有确认文案，再补一句「Hub 上本设备的记录不会自动吊销」。【码】`App.tsx:258` 断开重配时只清本地数据，没有调用吊销。
- 每个区块的错误就近显示，不再集中到面板底部。

## 4. 容易漏掉的回归和代码风险

- 配对时探测线路的逻辑必须保留：核对 Hub 公钥是否和二维码一致，并且禁止跟随重定向。如果以后要加"测试连接"，必须复用这套核对，不能只看能不能打开。
- `App.tsx:64` 在新设备被批准**之前**就把身份保存到本地了。如果在配对码页面加"返回"，要像出错时那样，把已保存的身份和系统钥匙串里的密钥一起删掉。
- 计算线路的函数有个参数用来保留旧线路名，两处调用都不能丢，否则旧的 Tailscale 线路会被改名成"主机直连"。
- 中转默认改为空以后，切换到"通过其他 VPS 中转"时仍要自动补一条空行（`App.tsx:68` 的现有逻辑）。
- `client/src/RouteFields.tsx:16` 中转行用序号当 key，上移/下移时输入框会错位，应改用固定 id。
- 邀请新设备的二维码必须继续用已保存的线路，不能用编辑中还没保存的草稿。
- 分页后切换分类会卸载组件：线路草稿丢失要按"离开"处理并提示；通知设置会重新拉取一次。
- 导航里显示哪些分类，要直接判断是不是桌面应用或手机原生应用，不能先渲染组件再看它是不是空的。
- 时区：两个勿扰时间改动或提交时都要写入当前时区。
- Android 返回键应依次是：详情页 → 分类列表 → 关闭设置。我没看到现有的返回键处理，需要核实。
- 新增文案都要补英文翻译。
