# 在浏览器中使用 TaroBird

TaroBird 主机已经通过 `client/dist` 直接提供完整网页客户端。无需安装原生 App，你可以直接配对任意现代桌面或手机浏览器（Chrome、Safari、Edge、Firefox），同步与 App 一致的全部对话，并随时在设备列表中吊销该浏览器。

## 从已配对 App 发起浏览器配对

1. 在已配对的电脑或手机上打开 **设置 → 设备与网络 → 添加设备**。
2. 将邀请页顶部从 **配对 App** 切换为 **在浏览器中使用**。
3. 选择一条浏览器可信任的访问线路（见下方 HTTPS 与来源配置说明）。
4. 复制一次性浏览器配对链接，或用手机系统相机直接扫描二维码（本机回环链接仅支持复制，因为 `127.0.0.1` 仅在运行主机的这台电脑上有效）。
   - 一次性邀请令牌仅放在 URL 片段（`#pair=...&invite=...`）中，不会进入 HTTP 请求路径、服务端或反代日志和 `Referer` 头；页面打开后会立刻从地址栏和历史记录中移除片段。
5. 在浏览器中点击 **配对此设备**，页面会显示 8 位配对码。
6. 在已信任设备上打开 **设备与网络 → 输入配对码确认**，输入该 8 位配对码并确认授权。
7. 浏览器随即连接并同步对话，同时以 `web` 设备显示在主机的 **设备列表** 中；撤销授权后会立刻断开会话与 WebSocket。

## HTTPS 证书与允许来源（`origins`）要求

浏览器严格遵循系统 WebPKI HTTPS 信任链（不同于原生 TaroBird App 可以固定主机自签名私有 CA），并且主机对 HTTP API 与 WebSocket 升级实施显式 `Origin` 白名单校验：

- **主机本机回环（`http://127.0.0.1:<port>` 或 `http://localhost:<port>`）**：
  - 在运行主机的电脑上开箱即用；浏览器将回环地址视为安全上下文（Secure Context），主机也会自动放行当前非 TLS 回环监听端口对应的 `127.0.0.1`、`[::1]` 和 `localhost` 来源。
- **VPS 中转或公网 HTTPS 主机（`https://<vps-host>:<port>`）**：
  - 需要具备公共受信任 HTTPS 证书，并且在主机 `config.json` 的 `"origins"` 中显式加入精确的浏览器来源（包含协议、域名与非默认端口，不要写 `*`）。
- **Tailscale HTTPS（`tailscale serve`）**：
  - 通过 `tailscale serve` 提供 Let's Encrypt 信任证书的 `https://<host>.<tailnet>.ts.net` 域名，同时必须在主机 `config.json` 的 `"origins"` 中加入该精确来源（否则主机会以 `403 origin_forbidden` 拒绝浏览器请求）。
- **私有局域网或 Tailscale IP HTTPS（`https://192.168.x.x:8788`、`https://100.64.x.x:8788`）**：
  - 使用主机私有自签名证书（公共 CA 也无法为私网/CGNAT IP 签发受信任证书），浏览器会拒绝连接。**切勿手动绕过或忽略浏览器的证书安全警告**，请切换到受信任 HTTPS 线路（VPS 中转或 Tailscale HTTPS 域名）或使用原生 TaroBird App。

在主机的 `config.json` 中合并 `"origins"` 配置示例（保留原有 `host`、`port`、监听与中转字段）：

```json
{
  "origins": [
    "https://hub.example.com:8443",
    "https://<host>.<tailnet>.ts.net"
  ]
}
```

完整配置可参考 [主机与中转部署](host-deployment.md) 与 [VPS 中转手动指南](vps-relay-manual.zh-CN.md)。

## 浏览器功能支持矩阵

已覆盖桌面浏览器（Chrome、Safari、Edge、Firefox）与手机浏览器（iOS Safari、Android Chrome）：

| 功能 | 浏览器网页版 | 说明 |
| --- | --- | --- |
| 一对一 Bot 对话、流式回复、Markdown、公式、代码、Widget | **支持** | 与原生 App 同步同一套对话 |
| 群聊、话题、ADHD 面板、搜索、文件夹 | **支持** | 状态与权限一致 |
| 文件上传、附件预览与下载 | **支持** | 使用浏览器标准下载 |
| 工作台：画布、幻灯片、白板（Excalidraw）、笔记（Vditor） | **支持** | 完整编辑与版本历史 |
| 语音输入（麦克风） | **支持（HTTPS / localhost）** | 需安全上下文及浏览器麦克风权限 |
| 设备管理与即时吊销 | **支持** | 显示为 `web` 设备 |
| 远程屏幕控制 | **仅原生 App（隐藏）** | 依赖原生桌面/移动屏幕传输 |
| 工作台内嵌网页标签页 | **仅桌面端（禁用）** | 界面明确提示“网页仅在桌面端可用” |
| 后台推送通知 | **推荐 Web Push / App** | 需主机配置 Web Push；打开页面时实时更新 |
| 在访达 / 资源管理器中显示下载文件 | **仅桌面端** | 浏览器使用自身下载列表 |

## 安全说明

- 每个配对的浏览器都在当前来源的浏览器存储中独立生成设备密钥，并走完整的 8 位主人确认流程。
- 浏览器配对片段（`#pair=...&invite=...`）在配对前会严格校验是否与当前站点来源及主机公钥一致，并在加载后立刻从地址栏和历史记录中移除。
- 请勿在公共电脑或共享浏览器上配对；若需远程登出，在任意已配对设备的 **设置 → 设备与网络** 中撤销该浏览器即可立即生效。
- 托管型多租户网页中转不在本自托管网页客户端范围内；你的浏览器始终直连自己的主机。
