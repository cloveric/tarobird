# 链接预览：默认卡片，样式移入设置

输入框取消「发送为：标题 / 卡片」，默认使用卡片。在「设置 → 通用 → 消息 → 链接预览样式」选择标题或卡片，立即应用到本设备待发送的链接，并在重启后保留。已发送消息、其他设备的发送偏好不变；消息自身的样式继续随同步和转发保留，阅读时的展开/收起仍是本地操作。

标题模式显示紧凑的标题和域名，不显示摘要、封面或卡片底色；卡片模式显示网页提供的标题、摘要和封面。标题模式的文字、域名和图标使用用户消息气泡的颜色，兼容 CLI、黑白等主题。

## 复现与修复

用户截图中的预览只有域名和「打开原链接」，没有网页标题、摘要或封面。定位发现草稿 CSS 将所有 `.link-preview-description` 隐藏，连读取中/读取失败的说明也不可见。用不可访问网页的隔离测试复现：DOM 中存在「打开原链接」，可见性断言失败。

现在草稿显示一行摘要或状态说明；读取失败时明确显示「未能读取网页信息，可打开原链接」。这不改变网页获取权限或绕过站点限制，也不代表任意网页都能获取摘要。

偏好保存在现有设备设置中。旧配置缺少该字段或值无效时回退为卡片；旧富草稿的样式字段仍兼容读取，但不覆盖新设备偏好。文本、附件、引用、关闭预览及选择链接继续使用原有草稿持久化。
