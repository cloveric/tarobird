# 图片查看器右键菜单与复制

桌面容器会拦截系统右键菜单，原先只接入了文字编辑操作。图片查看器未提供自己的菜单，因此右键图片时没有可用操作。

共享 `ImageViewer.tsx` 现在提供“复制图片”、另存为、放大/还原、长图适应窗口/宽度和全屏操作。菜单放在图片的原生 dialog 内，避免被顶层模态遮挡或变为 inert。沿用 `DesktopMenu` 的焦点、定位、外部点击、滚动和窗口变化关闭规则；新增可选 portal 容器不改变其他菜单的默认行为。

- ⌘C / Ctrl+C 复制当前图片，Shift+F10 / 菜单键打开菜单。菜单中的方向键不会切换图片；Esc、返回操作先关闭菜单。
- 复制使用已经取得的完整原图 Blob，与当前缩放、拖动位置无关，不复制缩略图、临时 URL 或查看器截图。
- PNG 直接交给剪贴板；JPEG、SVG 等可解码格式按原始尺寸转换为 PNG，保留透明通道。动图复制解码出的静态帧，保留动图应使用另存为。超出转换内存边界时明确报错，不静默缩小。
- 按 [WebKit 的剪贴板约束](https://webkit.org/blog/10855/async-clipboard-api/)，在点击/按键回调里立即发起写入，把异步转换作为 `ClipboardItem` 的 Promise，避免用户激活在转换期间失效。
- 未加载的图片不能复制；环境不支持剪贴板时菜单项禁用。拒绝或转换失败显示错误。等待期间防止重复操作，切图或关闭后不把旧操作的成功提示显示给另一张图。
- 另存为仍使用选中的原文件，不改变原始格式或字节。主对话、侧边、ADHD、草稿和文件列表共用查看器。

这是客户端交互修订，CLI 不适用：没有改变 Host、下载权限、附件协议、存储或命令行能力，也没有改字号和各平台的布局密度。
