# Flat macOS menu-bar icon — 2026-10-13

The previous repair removed the icon's square background but retained the
coloured, shaded mascot and explicitly disabled template rendering. It did not
meet the requested monochrome, two-dimensional menu-bar style.

`assets/brand/tray-macos.svg` now owns a compact flat silhouette with transparent
eye cutouts. The existing generator renders it into a 36px RGBA image for the
18pt status item. `main.rs` enables AppKit template rendering, which supplies the
native foreground (white on dark/tinted menu bars, dark on light menu bars) and
the highlighted-menu appearance. The launcher/Dock artwork remains the selected
colour master. The earlier coloured tray master is retained as source history
but is no longer used to generate shipping icons.
