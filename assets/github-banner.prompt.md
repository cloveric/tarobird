# Current GitHub social artwork

The current banner is reproducible SVG typography and layout around the
owner-selected phoenix, with the TaroBird wordmark (2026-11-04). It does not
generate a second mascot or a mock UI. Source: `github-banner.svg`, rendered by
`scripts/render-brand-preview.mjs`. The phoenix is the same transparent master
used by the App scenes and README covers, with a soft shadow so its cream belly
stays distinct from the cream backdrop; see
`brand/brand-identity.json` and `brand/README.md` for provenance.

The earlier watercolor `github-banner-art.png` belongs to the retired
TaroCub/Lark-first banner and is no longer a dependency of this artwork.
