# Original Bot avatar sheets

These are the seven unmodified images supplied by the project owner. Their
bytes were verified against the provided originals before moving them out of
the client runtime assets. Keep them for reproducible crops; do not import them
into the shipped client.

Run `python3 scripts/crop-bot-avatars.py` from the repository root to regenerate
the 63 small portraits. See `client/src/assets/bot-avatars/README.md` for source
filenames, format, identity and packaging details.
