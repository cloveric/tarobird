# JetBrains Mono

Official upstream: https://github.com/JetBrains/JetBrainsMono

Pinned source commit: `19371302b95d218af43299bce79ddbddd0bc364d`. Original Regular and SemiBold WOFF2 files
from `fonts/webfonts/`, distributed unchanged under the included SIL OFL 1.1.
The App also distributes the license at `/licenses/JetBrains-Mono.txt`.

Used for CLI Latin text, with Sarasa Term SC retained for Chinese. These fonts
are bundled for offline reading; no external font service is required.
